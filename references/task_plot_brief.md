# Task plot brief

Title: Visual Crowding Task
Construct: peripheral letter identification / spatial crowding

Evidence: main.py, src/run_trial.py, config/config.yaml and README.md inspected after native gates stabilized. Author-adapted design, not a Bouma replication.

Three representative rows: Unflanked, Near (.25 E), Far (.75 E). All examples use a right peripheral lowercase a at the same eccentricity. Two simultaneous x flankers are close to the target for Near and more widely spaced for Far. Fixation is a small filled black square at screen center. The target is never at fixation.

Every row: Fixation (600 ms, fixation only, no response) → Array (200 ms fixed, fixation + peripheral target/optional x flankers, no response) → Report (4000 ms max, fixation retained and lower Chinese prompt 报告字母, no target/flankers) → Intertrial (300 ms, fixation only). Report accepts 25 letters excluding x or F8 (self-reported fixation departure); RT begins at report onset. No feedback phase.

The full task also includes .40E/.55E spacing, 3°/6° eccentricities and both left/right hemifields; representative rows collapse these variants. 500 trials, five blocks of100, with self-paced breaks. Plot does not diagram registration, instructions or breaks, and labels itself a trial schematic.

Geometry must be schematic, not claimed angular scale or a demonstration of a measured crowding effect. No accuracy curves, normative thresholds or gaze-verification claim.
