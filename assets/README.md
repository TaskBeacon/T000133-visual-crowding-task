# Assets

The26lowercase PNGs are task stimulus glyphs rendered from Windows Courier New regular using scripts/prepare_materials.py. The font file is not distributed. Glyph rasterization is a modern font adaptation, not the original1970 printing apparatus. All PNGs share the cell, baseline and native raster x-height in glyph_metrics.json. Both native and web variants reuse these exact bytes. The cell center defines letter placement; center-to-center separation is not an ink-edge gap.

Chinese instruction text uses SimHei. No borrowed trial logic or human participant media are included. Rendering screenshots and synthetic records are software QA, not physical calibration.
